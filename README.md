# TaskHub Pro

Senior-grade MERN monorepo with TypeScript, Redux Toolkit, and more.

## Stack
- Backend: Express + TypeScript + MongoDB + Socket.io
- Frontend: React + TypeScript + Redux Toolkit + RTK Query
- Shared: Zod schemas + TypeScript types
- DevOps: Docker + GitHub Actions + Turbo

## Quick Start
\`\`\`bash
npm install
npm run dev
\`\`\`

## Packages
- `@taskhub/shared` — Shared types and schemas
- `@taskhub/backend` — Express API
- `@taskhub/frontend` — React app
